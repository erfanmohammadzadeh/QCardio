# PhysioNet ECG Signal Viewer

This guide provides instructions for setting up and using a QCardio application to view PhysioNet ECG signals from a local database.

## Prerequisites

- PhysioNet [MIT-BIH](https://physionet.org/content/mitdb/1.0.0/) database.
- Download application release Installation

## Installation

1. Install required packages and database.
2. Set database path on first page of application.
3. Select a Signal from first page and press Read.
